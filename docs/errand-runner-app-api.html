App - 骑手入驻接口文档

模块：com.htyoudao.youdao.module.errand.controller.app.errandRunner

基础信息

Base Path/errand/runner

接口范围本文档覆盖骑手入驻三个接口：提交申请、查询详情、修改申请。

会员 ID三个接口均通过 SecurityFrameworkUtils.getLoginUserId() 获取当前登录会员 ID，前端无需传 memberId。

门店入驻资料使用 storeId 保存门店 ID；详情接口额外返回 storeName。

审核状态auditStatus：0 待审核，1 通过，2 失败。

封禁状态banStatus：0 正常，1 封禁。

接口列表

POST/apply 提交骑手入驻申请

首次申请新增跑腿员资料；如果已存在待审核申请，不允许重复提交。

请求体

字段类型必填说明
storeIdlong/string是门店 ID
namestring是姓名
phonestring是手机号，需符合大陆手机号格式，且不能被其他会员占用
studentNostring是学号
idCardNostring是身份证号，不能被其他会员占用
genderinteger是性别，仅允许 2=女
idCardFrontstring是身份证正面图片地址
idCardBackstring是身份证反面图片地址
studentCardImgstring是学生证照片地址

请求示例

{
  "storeId": "2056265154128035842",
  "name": "张三",
  "phone": "18888888888",
  "studentNo": "20260001",
  "idCardNo": "341200200001010022",
  "gender": 2,
  "idCardFront": "https://example.com/id-front.jpg",
  "idCardBack": "https://example.com/id-back.jpg",
  "studentCardImg": "https://example.com/student-card.jpg"
}

响应示例

{ "code": 0, "data": "2057000000000000001", "msg": "" }

GET/apply-info 查询当前会员入驻详情

根据登录会员查询跑腿员资料，并根据 storeId 回填 storeName。

响应字段

字段类型说明
id/memberIdlong/string跑腿员 ID、会员 ID
storeIdlong/string门店 ID
storeNamestring门店名称，根据门店 ID 查询
name/phone/studentNo/idCardNo/genderstring/integer申请基础信息
idCardFront/idCardBack/studentCardImgstring证件图片地址
auditStatus/auditReason/auditTimeinteger/string/date审核信息
banStatus/banReasoninteger/string封禁信息
balance/frozenBalancedecimal余额信息
tranPasswordStatusinteger交易密码设置状态：0 未设置，1 已设置

PUT/apply 修改骑手入驻申请

审核中不可修改；审核通过或审核失败时允许修改。修改成功后 auditStatus 重置为 0，不清空审核原因、审核时间、审核人。

变更记录仅记录非图片字段：storeId、name、phone、studentNo、idCardNo、gender。图片字段变更会更新主表，但不写入变更记录。

请求体

同 POST /apply。

响应示例

{ "code": 0, "data": true, "msg": "" }
