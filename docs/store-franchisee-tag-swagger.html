变更概览

本次门店变更包含：门店分页最多 100 个标签的组合筛选；门店新增、修改、详情接入一对一加盟商资料；提供城市门店缓存手动全量刷新接口。
  • 多标签筛选复用 system_store_tag，不新增标签字段或关系表。
  • 加盟商信息存入独立表 system_store_franchisee_info，不进入城市门店列表缓存。
  • 加盟商手机号、身份证号、银行卡号为敏感字段，门店详情和有导出权限的门店列表导出可完整获取。
  • 后台路由通常增加 /admin-api 网关前缀。

POST/system/store/page门店分页及多标签筛选

JSON Body 权限：system:store:query

{
  "pageNo": 1,
  "pageSize": 20,
  "text": "0090",
  "tagIds": [1024, 1025],
  "type": 1
}
新增字段类型必填说明
tagIdsLong[]否多选标签 ID，最多 100 个；后端去重并忽略 null
typeInteger否1 同时满足全部标签，2 满足任意标签，3 无标签

筛选规则

场景行为
type=1 且 tagIds 非空门店必须同时拥有全部所选有效标签
type=2 且 tagIds 非空门店拥有任意一个所选有效标签即可
type=3忽略 tagIds，仅返回没有任何有效标签关系的门店
type=1/2 且 tagIds 为空不增加标签条件
新旧字段同时传入tagIds + type 优先于旧字段 tagId
仅传旧 tagId=-1继续表示无标签，保持旧调用兼容

返回 PageResult<StoreResVO>，不会因门店命中多个标签产生重复记录或错误分页总数。

GET/system/store/export按相同标签条件导出门店

Query 权限：system:store:export。复用分页接口的标签规则，支持 tagIds 与 type，同时兼容旧 tagId。

GET /system/store/export?tagIds=1024&tagIds=1025&type=1

接口返回“数据下载中”提示，导出任务异步执行。Excel 增加加盟商姓名、手机号、身份证号、开户行、开户省份、开户城市、银行卡账号七列；没有加盟商资料的门店对应列为空。每页批量查询加盟商资料，避免逐门店查询。

PUT/system/store/update修改门店及加盟商资料

JSON Body 权限：system:store:update。storeId 必填。

franchiseeInfo 传值处理规则
不传或 null保持原加盟商资料不变，兼容旧前端
非空对象按完整对象覆盖；单个空字段会清空原字段
所有字段均为空逻辑删除加盟商关系
资料曾被删除后重新提交恢复原物理记录，不产生唯一索引冲突

DELETE/system/store/delete?storeId={storeId}删除门店并删除加盟商关系

Query 权限：system:store:delete。删除门店时同步逻辑删除对应加盟商信息，接口参数和返回结构没有变化。

POST/system/store/refresh-city-list-cache手动同步刷新城市门店列表缓存

权限：system:store:update。无请求参数，返回 CommonResult<Boolean>。用于人工修复缓存或发布后主动全量校准。

{
  "code": 0,
  "data": true,
  "msg": ""
}

加盟商信息模型

字段类型必填校验与说明
franchiseeNameString否姓名，最多 64 字符
franchiseeMobileString否有值时按大陆手机号规则校验，最多 20 字符
idCardNoString否有值时按标准身份证规则校验，最多 32 字符
bankNameString否开户行，最多 128 字符
bankProvinceString否开户省份名称，最多 64 字符
bankCityString否开户城市名称，最多 64 字符
bankCardNoString否8 至 32 位数字；保存时移除空格

数据库变更

执行文件：sql/system_store_franchisee_info.sql

CREATE TABLE IF NOT EXISTS `system_store_franchisee_info` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT COMMENT '主键',
  `store_id` bigint(20) NOT NULL COMMENT '门店ID',
  `franchisee_name` varchar(64) DEFAULT NULL COMMENT '加盟商姓名',
  `franchisee_mobile` varchar(20) DEFAULT NULL COMMENT '加盟商手机号',
  `id_card_no` varchar(32) DEFAULT NULL COMMENT '加盟商身份证号',
  `bank_name` varchar(128) DEFAULT NULL COMMENT '开户行',
  `bank_province` varchar(64) DEFAULT NULL COMMENT '开户省份',
  `bank_city` varchar(64) DEFAULT NULL COMMENT '开户城市',
  `bank_card_no` varchar(32) DEFAULT NULL COMMENT '银行卡账号',
  `creator` varchar(64) NOT NULL DEFAULT '',
  `create_time` timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updater` varchar(64) DEFAULT '',
  `update_time` timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  `deleted` bit(1) NOT NULL DEFAULT b'0',
  `tenant_id` bigint(20) NOT NULL DEFAULT '0',
  `business_id` bigint(20) DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_store_franchisee_info_store_id` (`store_id`)
);

多标签筛选只修改查询 SQL，不需要执行额外 DDL。
