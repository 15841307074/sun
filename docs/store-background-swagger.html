PUT/system/store/background/update-status修改门店背景模板发布状态
operationId: updateStatus

说明

自定义模板发布或关闭的唯一入口。状态确实发生变化时更新 releaseTime；状态值相同时不更新时间，但会重新构建受影响门店缓存。

系统默认模板禁止调用该接口，始终保持发布状态。

Request body required

字段类型必填说明
backgroundIdinteger(int64)是模板编号。
publishStatusinteger(int32)是0 关闭，1 发布。
{
  "backgroundId": 208900000000000001,
  "publishStatus": 1
}

200 响应

{ "code": 0, "data": true, "msg": "" }
状态提交后会异步重建受影响门店缓存。指定门店和标签模板优先于全部门店模板；同一优先级按 releaseTime DESC, backgroundId DESC 选择最新模板。

Schemas　数据模型

StoreBackgroundSaveReqVO

字段类型必填说明
backgroundIdinteger(int64)修改必填模板编号。
templateNamestring是模板名称，不允许重复。
backgroundImagestring是背景图片 URL。
appScopeinteger(int32)是应用范围：1 按门店，2 按标签。
storeScopeinteger(int32)按门店必填门店范围：1 全部门店，2 部分门店。
storeIdsarray<integer(int64)>部分门店必填门店编号，多选。
tagIdsarray<integer(int64)>按标签必填标签编号，多选，任意标签命中。

StoreBackgroundRespVO

字段类型说明
backgroundIdinteger(int64)模板编号。
templateNamestring模板名称。
backgroundImagestring背景图片 URL。
appScopeinteger(int32)1 按门店，2 按标签。
storeScopeinteger(int32)1 全部门店，2 部分门店；按标签时可为空。
publishStatusinteger(int32)0 关闭，1 发布。
defaultFlaginteger(int32)0 自定义模板，1 系统默认模板。
releaseTimestring(date-time)发布时间，新建未发布模板为空。
storeIdsarray<integer(int64)>直接选择的门店编号。
tagIdsarray<integer(int64)>选择的标签编号。
applyStoreCountinteger(int32)模板实际命中的门店数量。
applyStoreNamesarray<string>实际适用门店名称；全店模板返回“全部门店”。
