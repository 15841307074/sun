# 学习任务接口实施进度

更新时间：2026-09-13

## 已完成

- 管理端学习任务创建、修改、上下架、删除、分页、详情、统计概览、门店进度列表与门店详情。
- 小程序资料分类、资料列表/详情、任务列表/详情、任务资料详情、访问上报、学习进度上报。
- 任务与资料仅保存 `material_id` 和任务规则，标题、文案、分类、上下架状态实时读取资料主表。
- 资料下架时隐藏但保留关系；重新上架后恢复。附件指纹变化时递增 `progress_revision`，旧进度留作历史且不参与当前进度。
- 同一负责人管理多家命中门店时，以用户主进度为唯一事实来源，并同步生成所有门店的轻量进度投影。
- 任务 PV/UV 使用按月 ES 索引和前端 `visitId` 幂等写入；ES 操作不占用数据库事务。
- 进度写入使用 Redis 用户任务级锁、数据库唯一键及乐观锁；事务短小、批量上限 500、固定写入顺序，未使用并行数据库查询。
- App任务分页按当前页批量预取资料、文件进度、资料进度和用户主进度；单任务鉴权只读取当前负责人门店，避免加载任务全部门店。
- 已生成建表脚本、接口文档和风险说明。

## 已验证

- 已使用测试库真实 `bpm_learning_material.text` 样例核对 JSON 结构：富文本、文档 `file.url`、图片/视频 `url` 均可解析。
- Maven 编译命令：`mvn -pl youdao-module-bpm/youdao-module-bpm-biz -am -DskipTests compile`。
- 2026-09-13 最终改动已编译通过；`LearningMaterialContentParserTest` 共 4 项测试全部通过。

## 恢复执行时优先检查

1. 核对 `sql/bpm_learning_task.sql` 后在测试环境建表，再进行接口联调和并发压测。
2. ES 不可用、资料下架/重新上架、负责人变更、多门店同步、重复心跳和附件修订冲突均需做集成测试。

## 已确认的业务边界

资料附件从 A 改成 B，之后又恢复成完全相同的 A，如果期间没有任务接口访问，任务侧无法识别中间变化。由于资料只能下架后编辑，本方案以重新上架时的最终附件内容和上次有效内容比较；最终内容完全相同则不重置进度。
