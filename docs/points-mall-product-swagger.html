积分商城商品接口文档

Swagger 风格 · 版本 1.0 · 2026-09-03
说明改造说明公共响应 管理后台商品列表新增商品修改商品修改上下架商品详情 小程序商品分类列表商品详情兑换记录/详情 数据模型附件模型优惠券信息数据库变更

改造说明

没有新增商品状态字段。 商品上下架复用 isAvailable（1 已上架、2 已下架），售罄状态继续使用 productStatus（1 已售罄、2 正常）。优惠券通过现有 couponCode 查询，不新增 couponId。
  • 商品名称最多 20 字，商品描述最多 200 字。
  • 头图最多 5 个，支持图片和视频；详情最多 5 个，仅支持图片。
  • 视频 10MB 由前端上传时限制，后端校验 URL、类型和数量。
  • 小程序只展示已上架商品，售罄商品继续返回。

公共响应

{
  "code": 0,
  "data": {},
  "msg": ""
}
字段类型说明
codeInteger0 成功，其他值为业务异常
dataObject接口业务数据
msgString响应说明

管理后台接口

GET/member/points-product/list查询积分商品分页列表

Query 后台部署通常增加 /admin-api 前缀。

参数类型必填说明
pageNoLong否页码
pageSizeLong否每页条数
productNameString否商品名称模糊查询
productTypeInteger否1 优惠券，2 实体商品
isAvailableInteger否新增筛选：1 已上架，2 已下架

返回 PageResult<PointsProductDO>。列表不组装商品详情附件，完整附件通过详情接口获取。

POST/member/points-product新增积分商品

JSON Body 未传 isAvailable 时默认上架。

{
  "productName": "0090定制手机支架",
  "productSort": 10,
  "productType": 2,
  "productPrice": 999,
  "isAvailable": 1,
  "productDescription": "积分商城实体商品",
  "requiresShipping": 1,
  "productInventory": 74,
  "productCategoryId": 1001,
  "productHeaderAttachments": [
    {"url": "https://example.com/header.jpg", "type":2},
    {"url": "https://example.com/demo.mp4", "type":1}
  ],
  "productDetailAttachments": [
    {"url": "https://example.com/detail.jpg", "type":2}
  ]
}
重点字段类型规则
productNameString必填，最多 20 字
productDescriptionString最多 200 字
isAvailableInteger1 已上架，2 已下架；未传默认 1
productHeaderAttachmentsAttachment[]最多 5 个，允许 1 视频 / 2 图片
productDetailAttachmentsAttachment[]最多 5 个，仅允许 2 图片
couponCodeString优惠券商品填写，作为实时查询关联编码

返回 CommonResult<Integer>，data 为影响行数。

POST/member/points-product/edit修改积分商品

请求结构与新增一致，额外要求 productId 必填。附件 List 按提交内容覆盖，同时维护历史 URL 字段。

{
  "productId": 208900000000000001,
  "productName": "0090定制手机支架",
  "productSort": 10,
  "productType": 2,
  "productPrice": 999,
  "isAvailable": 1,
  "productDescription": "修改后的商品描述",
  "productInventory": 74,
  "productHeaderAttachments": [{"url":"https://example.com/new.jpg","type":2}],
  "productDetailAttachments": [{"url":"https://example.com/detail.jpg","type":2}]
}
PUT/member/points-product/update-availability独立修改小程序上下架状态 
{
  "productId": 208900000000000001,
  "isAvailable": 2
}
字段类型必填说明
productIdLong是积分商品 ID
isAvailableInteger是1 上架，2 下架

只修改 isAvailable，不会修改售罄状态、库存或其他商品字段。

GET/member/points-product/{productId}后台商品详情

productId 为路径参数。新增或重点返回字段：

字段类型说明
productThumbnailString商品独立封面图
productHeaderAttachmentsAttachment[]头图/视频及类型
productDetailAttachmentsAttachment[]详情图片及类型
isAvailableInteger1 已上架，2 已下架
couponForProduct.couponInfoPointsProductCouponDetailVO优惠券商品按 couponCode 查询的实时完整优惠券信息

优惠券查询异常时，couponInfo 返回 null，不影响商品详情返回。

小程序接口

GET/member/points-product/listDTO商品列表与分类筛选

Query 小程序部署通常增加 /app-api 前缀。

参数类型必填说明
productTypeInteger否新增：不传全部，1 优惠券，2 实体商品

仅返回 isAvailable=1 的商品；售罄商品仍返回。

附件模型 Attachment

字段类型必填规则
urlString是合法 URL，最大 2048 字符
typeInteger是1 视频或 2 图片

头图允许 1 视频 / 2 图片；详情仅允许 2 图片。每组最多 5 个。

优惠券实时信息 couponInfo

类型为积分商品详情专用的 PointsProductCouponDetailVO，通过 couponCode 查询，不影响原优惠券接口。主要字段：

字段类型说明
idLong优惠券主键
couponCodeString优惠券编码
couponNameString优惠券名称
couponTypeInteger0 满减券，1 折扣券
couponNumInteger剩余数量
limitNumInteger每人限领数量
couponStartTimeDateTime有效开始时间
couponEndTimeDateTime有效结束时间
fullReductionInteger满减门槛
reduceAmountDecimal优惠金额
discountString折扣
isGroundInteger0 未上架，1 已上架
couponExplainString优惠券说明
useRulesString使用规则
couponImageUrlString优惠券图片
isCommonInteger1 通用，2 门店券
useTypeInteger有效期类型
useTimeString有效期信息
habitInteger0 全部，1 堂食，2 外卖
doorsillType / doorsillInteger / Decimal使用门槛类型及门槛金额或件数
isCommonStoreInteger适用商品范围
claimTimeLimitInteger是否限制领取时间
couponStoresCouponStoreInfoVO[]适用门店或门店标签明细
couponCommoditiesCouponCommodityInfoVO[]指定可用或不可用商品明细

数据库变更

执行文件：sql/points_product_attachments.sql

ALTER TABLE `points_product`
  ADD COLUMN `product_header_attachments` TEXT NULL
    COMMENT '商品头图附件JSON，最多5个，支持1视频和2图片'
    AFTER `product_header_image`,
  ADD COLUMN `product_detail_attachments` TEXT NULL
    COMMENT '商品详情附件JSON，最多5个，仅支持2图片'
    AFTER `product_detail_images`;

不新增 is_available、product_status、coupon_code 或 coupon_id。
