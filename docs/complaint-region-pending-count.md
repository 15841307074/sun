# 投诉管理待处理数量角标

`GET /app-api/system/complaint/getRegionPendingCount`

需要账号登录，沿用现有登录令牌和当前业务项目上下文。无请求参数，不接受前端指定区域或门店范围。

统计范围为当前登录账号所属组织及下级的所有门店，与该账号直接关联的店长门店（`system_store_user.type=1`）的并集。门店去重；只统计当前项目中 `complaint_type=0` 且未删除的投诉。没有组织门店及店长门店权限时返回 0。

成功响应示例：

```json
{"code":0,"data":12,"msg":""}
```

登录完成、进入投诉管理页面、切换当前项目，以及处理投诉成功后调用，使用 `data` 更新角标。0 时由前端隐藏角标。数量不随当前选中的门店改变，也不限制投诉创建时间。

接口实时执行计数，不新增缓存、数据库字段或迁移脚本。原有投诉列表、投诉详情和处理接口保持原调用方式。
