抽签 C 端接口文档

接口前缀：/promotion/activity-cq

返回包装：CommonResult<T>，分页返回：PageResult<T>

当前抽签玩法为“任务直接发签码”，不再保留手动抽签发码流程。

1. 已废弃接口

  • draw/verify
  • draw/count
  • draw
  • getActivityCqList

3. 任务相关

3.1 获取任务列表

POST /task/getTaskList

字段类型必填说明
activityIdLong是活动 ID
memberIdLong是用户 ID
storeIdLong否门店 ID

返回 List<TaskVO>

字段类型说明
taskTypeInteger任务类型，1签到 2下单 3分享 4免费集签 5浏览首页
amountBigDecimal下单金额门槛
taskLimitInteger完成上限
finishCountInteger已完成数量

3.1.1 参与抽签活动

POST /join

字段类型必填说明
activityIdLong是活动 ID
memberIdLong是用户 ID
storeIdLong否门店 ID
  • 用户首次点击“立即参与抽签”时调用。
  • 接口会复用活动缓存做活动校验。
  • 已参与过时直接返回成功，接口幂等。
  • 参与成功后，详情接口会返回 joined=true。

3.2 完成签到任务

POST /task/sign

字段类型必填说明
activityIdLong是活动 ID
memberIdLong是用户 ID
storeIdLong否门店 ID
  • 签到成功后直接生成签码。
  • 会校验任务开关和签到上限。
  • 已到开奖时间或活动已开奖时不可再签到得码。

3.2.1 完成普通分享任务

POST /task/share/simple

字段类型必填说明
activityIdLong是活动 ID
memberIdLong是当前用户 ID
storeIdLong否门店 ID
  • 当前抽签活动推荐使用该接口完成分享任务。
  • 用户只要完成一次普通分享，即可累计一次分享任务并获得签码。
  • 不依赖 activity_help 助力关系表。
  • 会校验用户是否已参与活动，以及分享任务次数上限。

3.2.2 完成浏览首页任务

POST /task/browse/home

字段类型必填说明
activityIdLong是活动 ID
memberIdLong是当前用户 ID
storeIdLong否门店 ID

返回 List<String>，表示本次新增的抽签码列表。

  • 浏览首页成功后直接生成签码。
  • 会校验用户是否已参与活动。
  • 会校验浏览首页任务开关和当日次数上限。
  • 已到开奖时间或活动已开奖时不可再获得签码。

3.3 分享助力预校验

POST /task/shareCheck

字段类型必填说明
activityIdLong是活动 ID
memberIdLong是助力人用户 ID
inviterMemberIdLong是被助力人用户 ID
storeIdLong否门店 ID
  • 校验是否允许助力。
  • 校验是否重复助力。
  • 校验单日助力上限。
  • 该接口为历史助力模型保留，不作为当前抽签玩法主入口。

3.4 完成分享助力任务

POST /task/share

字段类型必填说明
activityIdLong是活动 ID
memberIdLong是助力人用户 ID
inviterMemberIdLong是被助力人用户 ID
storeIdLong否门店 ID
  • 分享助力成功后，给 inviterMemberId 发签码。
  • 新会员助力时当前实现会额外奖励签码。
  • 已到开奖时间或活动已开奖时不可再分享得码。
  • 该接口为历史助力模型保留，不作为当前抽签玩法主入口。

5. 签码与结果查询

5.1 获取抽签记录

POST /record/draw

字段类型必填说明
activityIdLong是活动 ID
memberIdLong是用户 ID
pageNoInteger是页码
pageSizeInteger是每页数量

返回 PageResult<DrawRecordVO>

字段类型说明
idLong记录 ID
signCodeString签码
obtainTypeInteger获取方式，1签到 2下单 3分享
resultStatusInteger结果状态，0待开奖 1未中签 2已中签
prizeIdLong奖品 ID
prizeTypeInteger奖品类型
prizeContentString奖品内容
prizeImgUrlString奖品图片
prizeStateInteger奖品状态
drawTimeLocalDateTime签码生成时间

5.2 获取我的抽签码汇总

POST /code/my

字段类型必填说明
activityIdLong是活动 ID
memberIdLong是用户 ID

返回 MyCodeVO

字段类型说明
totalCountInteger总签码数
pendingCountInteger待开奖数
winningCountInteger中奖数
loseCountInteger未中奖数
signCountInteger签到获得数
orderCountInteger下单获得数
shareCountInteger分享获得数

5.3 获取我的抽签结果

POST /record/myResult

字段类型必填说明
activityIdLong是活动 ID
memberIdLong是用户 ID
pageNoInteger是页码
pageSizeInteger是每页数量

返回 PageResult<MyResultVO>

5.4 获取中奖公示列表

POST /record/winning

字段类型必填说明
activityIdLong是活动 ID
pageNoInteger是页码
pageSizeInteger是每页数量

返回 PageResult<WinningRecordVO>

6. 状态口径

  • activityStatus：0未开始 1已开始 2已开奖
  • drawStatus：0未开奖 1开奖中 2已开奖
  • resultStatus：0待开奖 1未中签 2已中签
  • prizeType：1兜底 2积分 3优惠券 4实物 5现金红包
  • prizeState：0已发放 1未填写收货地址 2已填写地址待发货 3已发货 9已退回

7. 业务补充

  • 用户签码来源只有三类：签到、分享助力、下单。
  • 不存在 C 端用户主动抽签生成签码的动作。
  • activity_cq_log 一条记录代表一张签码，同时承载最终开奖结果。
  • 开奖为统一批处理，不由 C 端触发。
